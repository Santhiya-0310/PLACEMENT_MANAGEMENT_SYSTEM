# 🎓 CampusHire – Placement Management System

CampusHire is a simple and user-friendly **web-based Placement Management System** developed to organize and manage college placement activities.

The system provides a centralized interface for managing **students, recruiting companies, job postings, and placement applications**.

---

## 📌 Project Overview

Managing placement activities manually can be time-consuming and difficult when student, company, job, and application information is maintained separately.

**CampusHire** provides a single web interface where placement-related information can be viewed and managed easily.

The project is developed using **HTML, CSS, and JavaScript** and can run directly in a modern web browser.

---

## ✨ Features

### 📊 Dashboard

* Total students count
* Partner companies count
* Open job postings count
* Students placed count
* Placement rate
* Recent job postings
* Placement notifications

### 👨‍🎓 Student Management

* Add student records

* Track CGPA and placement status

### 🏢 Company Management

* Add recruiting companies

* Industry information
* Contact email
* Company website

### 💼 Job Postings

* Add job opportunities
* Select recruiting company
* Package information
* Minimum CGPA requirement
* Application deadline
* Open/Closed job status

### 📝 Application Management

* Apply for available jobs
* Track applications
* Applied status
* Shortlisted status
* Placed status
* Rejected status
* Filter applications by status

## 🚀 How to Run

### Method 1 – Direct Browser

1. Download or clone this repository.
2. Open the project folder.
3. Open the HTML file.
4. The CampusHire application will open in your browser.

### Method 2 – Visual Studio Code

1. Open the project folder in **Visual Studio Code**.
2. Open the HTML file.
3. Run it using a browser.
4. No Python or Node.js installation is required for the current version.

---

## 💾 Data Storage

The current version uses **JavaScript in-memory data storage**.

This means:

* Data can be added and managed during the current session.
* No external database is required.
* Data resets when the webpage is refreshed.

A permanent database can be added in a future version.

---
